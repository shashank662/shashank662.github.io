INC-01 · MongoDB M20 · production● resolved

Cluster running out of memory

Impact
Memory exhaustion on the production MongoDB cluster.
Cause
Hot queries had no supporting index: ~3,000 documents scanned for every 5 returned.
Fix
Indexed the high-frequency query fields; scan-to-return fell under 100:1.

A service quietly leaking memory
